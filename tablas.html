Etiquetas de tablas
Etiqueta Función
<table> Se utiliza para crear una tabla en HTML.
<caption> Sirve para poner un título o descripción a la tabla.
<thead> Agrupa las filas que contienen los encabezados de la tabla.
<tr> Se utiliza para crear una fila en la tabla.
<th> Define una celda que funciona como encabezado de una fila o columna.
<tbody> Agrupa las filas que contienen los datos principales de la tabla.
<td> Define una celda que contiene datos de la tabla.
